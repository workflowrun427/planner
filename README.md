# Мой путь — личный дашборд для задач и привычек

Спокойное приложение: шаги по силам, опоры вместо «стриков», журнал побед, раздел поддержки.
Работает на телефоне как обычное приложение, **без аккаунтов и серверов** — данные лежат только в твоём устройстве.

## Как открыть у себя на компьютере
Дважды щёлкни `index.html`. Откроется в браузере. (Режим «приложение» и работа без интернета включаются только по https — см. ниже.)

## Структура папок
| Что | Зачем |
|---|---|
| `index.html` | страница-оболочка и нижняя панель вкладок |
| `css/style.css` | весь внешний вид (светлая и тёмная тема) |
| `js/` | логика: `store.js` (хранение), `domain.js` (правила), `view-*.js` (экраны), `app.js` (запуск) |
| `manifest.webmanifest`, `sw.js`, `icons/` | чтобы приложение устанавливалось на главный экран и работало без интернета |
| `tests/` | автоматические проверки (для тебя необязательны) |

## Где выложить по https (бесплатно)

Нужен адрес вида `https://…`: только так iPhone разрешает установку и работу без интернета.

### Рекомендую: GitHub Pages
Бесплатно, без карточки, надёжно. Условие: на бесплатном тарифе репозиторий должен быть **публичным**. Это нормально: в нём лежит только код приложения и нейтральные начальные данные. **Твои данные в репозиторий не попадают** — они остаются на телефоне.
Адрес сайта будет содержать твой логин на GitHub (`https://логин.github.io/название/`) — выбери такой логин и название, которыми не жалко «светить». Сайт открыт всем, кто знает адрес.

1. Зарегистрируйся на github.com (бесплатно).
2. Нажми **+ → New repository**. Название, например, `moy-put`. Выбери **Public**. Нажми **Create repository**.
3. На странице нового репозитория нажми ссылку **uploading an existing file**.
4. Открой папку `dashboard-project` в Finder. Нажми **⌘A** (выделить всё) и перетащи файлы в окно браузера. (Скрытая папка `.git` в Finder не видна и не выделится — так и надо.) Подожди, пока всё загрузится, нажми **Commit changes**.
5. В репозитории: **Settings → Pages**. В блоке *Build and deployment* в *Source* выбери **Deploy from a branch**, ветка **main**, папка **/ (root)**, **Save**.
6. Подожди до 10 минут. Наверху страницы Pages появится адрес сайта. Открой его.

**Как выложить обновление:** на странице репозитория **Add file → Upload files**, загрузи изменённые файлы. И **обязательно** увеличь число в `sw.js` в строке `const CACHE = 'mypath-v1'` (→ `v2`, потом `v3`…), иначе телефон будет показывать старую версию. После обновления приложение само предложит нажать «Обновить».

### Запасные варианты
- **Cloudflare Pages** — тоже бесплатно, щедрые лимиты для статичных сайтов, но настройка чуть длиннее.
- **Netlify** — удобно, но на бесплатном тарифе действует лимит «кредитов»: когда он кончается, проекты на месяц приостанавливаются. Для личного приложения лучше GitHub Pages.

## Как установить на главный экран iPhone
1. Открой адрес приложения в **Safari** (именно в Safari — в других браузерах кнопка установки на экран «Домой» работает иначе).
2. Нажми «Поделиться» (квадрат со стрелкой вверх внизу экрана).
3. Выбери **«На экран “Домой”»** → **Добавить**.
4. Дальше открывай приложение **только с иконки**.

> ⚠️ **Важно: Safari и приложение с главного экрана хранят данные раздельно.** Это известное поведение iOS (по словам разработчика WebKit, так сделано намеренно, см. [WebKit bug 181849](https://bugs.webkit.org/show_bug.cgi?id=181849)). Если ты сначала вносила данные в Safari, а потом установила приложение, оно будет пустым. Поэтому: **сначала установи, потом вноси данные.** Если уже внесла в Safari — сохрани копию в файл («Ещё → Сохранить копию в файл») и загрузи её в установленном приложении («Загрузить копию из файла»).
>
> Отдельный плюс: Safari стирает данные сайтов, которыми давно не пользовались (правило «7 дней»), но для приложений с главного экрана это исключено ([WebKit bug 237350](https://bugs.webkit.org/show_bug.cgi?id=237350)). Источники старые, поэтому проверяй сама (ниже) и сохраняй файл-копию.

## Как проверить, что данные не теряются
Сделай это один раз после установки, на своём телефоне:

1. **Закрой и открой.** Добавь в приложении что-нибудь (например, победу «проверка»). Смахни приложение вверх (закрой совсем), открой снова — запись на месте?
2. **Без интернета.** Включи авиарежим и открой приложение — должно открыться, записи на месте.
3. **Перезагрузка.** Перезагрузи телефон, открой приложение — записи на месте?
4. **Раздельность.** Открой тот же адрес в Safari. Скорее всего, там будет пусто или другое — это нормально, это другое хранилище. Ничего там не вноси.
5. **Копия.** «Ещё → Сохранить копию в файл» → выбери «Сохранить в Файлы». Найди файл в приложении «Файлы». Раз в неделю или перед сменой телефона делай такую копию.
6. **Ориентир внутри приложения.** В «Ещё → Где хранятся мои данные» показано: *«Данные ведутся с…»*. Если эта дата когда-нибудь вдруг станет сегодняшней, а ты ничего не стирала, — данные пропали: загрузи файл-копию.

Если в установленном приложении сверху «Ты во вкладке браузера» — значит, ты открыла его не с иконки.

## Синхронизация между телефоном и компьютером (через iCloud Drive)
Без аккаунтов и серверов: устройства обмениваются одним файлом `mypath-sync.json`. Приложение не может само заглядывать в iCloud, поэтому обмен делается кнопками в «Ещё → Синхронизация (iCloud)».

**Один раз:** включи iCloud Drive на айфоне и на Маке. На Маке: Safari → Настройки → Основные → «Место для загрузки файлов» → выбери папку в iCloud Drive (например, «Мой путь»).

**Закончила работать на одном устройстве:** «Ещё → ⬆ Только отдать». На айфоне выбери «Сохранить в Файлы» → iCloud Drive → та же папка (если спросит — «Заменить»).

**Села за другое устройство:** «Ещё → 🔄 Синхронизировать» → выбери `mypath-sync.json` из iCloud Drive. Данные объединятся: берётся запись, изменённая позже, удалённое не возвращается. Перед объединением приложение откладывает запасную копию («Ещё → Вернуть её»). Потом оно предложит сохранить обновлённый файл — согласись, чтобы другое устройство тоже получило всё.

Важно знать:
- Заметки из «Поддержки» в файл **не попадают** — они остаются только на устройстве.
- Это не автоматическая синхронизация: если забыть обменяться, на устройствах будут разные данные. Потом объединение их сольёт.
- Если правки на двух устройствах касаются одной и той же записи, остаётся та, что изменена позже.
- На Маке повторная загрузка может называться `mypath-sync 2.json` — бери самый свежий.
